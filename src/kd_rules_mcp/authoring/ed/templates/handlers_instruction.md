## Установка готовой выгрузки

1. Откройте окно расширений конфигурации, создайте или выберите ${extension_name}.
2. Загрузите файлы из папки `extension` **в расширение**. В основную конфигурацию их не загружайте.
3. Выполните проверку применимости расширения; при ошибке остановитесь и сохраните её текст.
4. Проверьте модули для сервера и внешнего соединения; обновите конфигурацию базы данных расширения.
5. Проверьте, что расширение активно. Расширение, созданное первой загрузкой из файлов, получает
   безопасный режим — снимите его; при обновлении существующего расширения режим сохраняется прежним.
   Решение принимает администратор; защиту всех расширений или всего сервера не отключайте.
   При записи этого свойства из кода: `Защита = Новый ОписаниеЗащитыОтОпасныхДействий; Защита.ПредупреждатьОбОпасныхДействиях = Ложь; Расширение.ЗащитаОтОпасныхДействий = Защита; Расширение.БезопасныйРежим = Ложь; Расширение.Записать();`.
6. Начните новый сеанс: расширение видно только новому сеансу. Затем выполните раздел «Проверка в базе».

### Пакетный конфигуратор

Запускайте из каталога комплекта; `<строка соединения>` подставляет администратор.
Учётные данные в комплект не входят. При ошибке любой команды остановитесь и сохраните её журнал.

```text
1cv8 DESIGNER /IBConnectionString "<строка соединения>" /LoadConfigFromFiles "extension" -Extension "${extension_name}" -Format Hierarchical
1cv8 DESIGNER /IBConnectionString "<строка соединения>" /CheckCanApplyConfigurationExtensions -Extension "${extension_name}"
1cv8 DESIGNER /IBConnectionString "<строка соединения>" /CheckModules -Server -ExternalConnection -Extension "${extension_name}"
1cv8 DESIGNER /IBConnectionString "<строка соединения>" /UpdateDBCfg -Extension "${extension_name}"
```

После команд выполните шаги 5–6: безопасный режим сам не снимается.

### Установка без конфигуратора базы

1. Создайте пустую файловую базу (`1cv8 CREATEINFOBASE File="<папка>"`).
2. Загрузите в неё папку `extension`: `1cv8 DESIGNER /F "<папка>" /LoadConfigFromFiles "extension" -Extension "${extension_name}" -Format Hierarchical`.
3. Сохраните расширение в файл: `1cv8 DESIGNER /F "<папка>" /DumpCfg "<файл>.cfe" -Extension "${extension_name}"`.
4. В целевой базе кодом: прочитайте файл в двоичные данные (файл должен быть доступен серверу 1С либо передан с клиента), получите расширение по имени или создайте новое, вызовите `ПроверитьВозможностьПрименения` и `Записать(ДвоичныеДанные)`.
5. Снимите безопасный режим и начните новый сеанс.
Основная конфигурация пустой базе не нужна: привязка объектов идёт по идентификаторам из комплекта.

## Ручное внесение

Основную конфигурацию не редактируйте. В новом или существующем расширении заимствуйте общий модуль
менеджера обмена и вставьте в него текст файла из папки `modules` целиком.
Если в расширении уже есть перехват заполнения правил конвертации объектов или перехват диспетчера,
второй не создавайте: остановитесь и пересоберите комплект с учётом существующего кода.
Сохраните модули, выполните проверку применимости, проверку модулей и обновление конфигурации базы данных
расширения. Снимите безопасный режим этого расширения по решению администратора и начните новый сеанс.
[/if]

## Проверка в базе

В согласованной песочнице, в новом сеансе:

1. Убедитесь, что установлена эта сборка: версия расширения ${extension_name} равна ${extension_version}.

${version_probe}

2. Прочитайте у целевого правила имя обработчика события: оно должно совпадать с именем из таблицы привязок.

${runtime_probes}

3. Передайте **новое** сообщение с объектом этого правила. Уже принятое сообщение проверкой не считается:
   БСП отклоняет его как принятое ранее.
4. Убедиться, что обработчик вызван, можно по его результату в сообщении или в объекте; число вызовов
   сервер доказывает по тексту модуля (одна ветка диспетчера, один вызов прежнего обработчика), обменом оно не
   наблюдается.
[if has_preset]
5. Для сохранения значения проверьте четыре случая: найденный и новый объект, сообщение со значением и без
   свойства. Сравните реквизит до и после и записи журнала регистрации.
[/if]

После обновления типовой конфигурации выполните новый просмотр и пересборку комплекта: имя типового обработчика
и порядок вызовов в новой версии могут измениться.

[if has_receive]
Если комплект добавляет получение нового объекта формата, первым выполните обмен из этой базы к корреспонденту:
список принимаемых объектов корреспондент узнаёт из её сообщения и хранит по версиям формата; до этого он такие
объекты не выгружает, ошибок при этом нет.
[/if]
