# Если не получилось

Шаг — номер шага установки в `SKILL.md`.

## Если не получилось

| Шаг | Симптом | Действие |
|---|---|---|
| 0 | `docker info` падает | закончить ход: человек запускает Docker Desktop |
| 0 | `docker info`: «unknown shorthand flag» | шаблон `--format` в двойных кавычках — взять строку шага 0 как есть (одинарные) |
| 3 | `ProjectConfigError` | текст называет поле и проект — исправить `projects.yaml`, показать человеку |
| 5 | «Нет projects.yaml» / «Нет папок проектов» | шаги 3–4; путь — папка проекта, не выгрузки |
| 5 | на месте `projects.yaml` каталог | `docker compose down`, удалить каталог, шаги 3–5 |
| 5 | `check_server.py`: недоступен (код 2) | `docker compose ps`, `docker compose logs kd-rules-mcp --tail 30`; занят порт 8060 — предложить человеку `port: 8061` и `server_url` с тем же портом в `projects.local.yaml` (шаг 4), затем `setup_local.py` и `docker compose up -d` |
| 5 | контейнер с именем `kd_rules_mcp` уже есть (другой клон) | его не трогать: второй экземпляр — `instance` и `port` в `projects.local.yaml` (шаг 4), затем `setup_local.py` и `docker compose up -d` |
| 5 | «папка НЕ видна» | проект не в `projects.local.yaml` или не перезапускали `setup_local.py` + `docker compose up -d` |
| 6 | инструментов `kd-rules-mcp` нет в клиенте | в той же сессии, что и запись `.mcp.json`, — так и должно быть: закончить ход, человек перезапускает клиент; после перезапуска — `claude mcp list`, одобрить сервер (Cursor — настройки MCP) |
| 6 | `structure_load_project`: «Нет каталога выгрузки» | поправить `dump`/`extensions` в `projects.yaml` (сервер перечитывает его при каждом вызове; если видит старое — редактор подменил файл: `docker compose restart`) |
| 7 | `prepare`: «База КД версии X, конфигурация Y» | база не из свежего шаблона — человек открывает её в 1С один раз |
| 8 | «Неверно указан пользователь или пароль» | логин базы: `dev_env` или `logins` — вписывает человек |
| 9 | после обновления `project_not_found` | снимок проекта не восстановился (лог контейнера: «Снимок … пропущен») — `rules_open` сохранённого файла |
| 9 | сборка образа падает | вывод `docker compose up -d --build` человеку; откат — шаг 9.6 |
