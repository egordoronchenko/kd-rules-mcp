# Шаг 4: projects.local.yaml

## 4. `projects.local.yaml`

```powershell
copy projects.local.example.yaml projects.local.yaml
```

В `projects:` — папки проектов на этой машине (ключи — как в `projects.yaml`). Остальное оставить, кроме двух
случаев (проверить до шага 5: `docker ps` — занят ли порт 8060 и есть ли уже контейнер `kd_rules_mcp`):

- **порт 8060 занят** — `port: 8061` (или другой свободный) и `server_url` с тем же портом
  (`http://localhost:8061/mcp`);
- **второй экземпляр сервера на этой машине** — `instance: <суффикс>` (буквы, цифры, `_`, `-`) и свой `port`:
  контейнер, том кэша и проект compose получают суффикс (`kd_rules_mcp_<суффикс>`), первый экземпляр не
  затрагивается.

`setup_local.py` (шаг 5) пишет из этих полей `.env` клона (`KD2_PUBLISHED_PORT`, `KD2_BIND`, `KD2_CONTAINER`,
`KD2_CACHE_VOLUME`, `COMPOSE_PROJECT_NAME`); тот же код `setup` в образе работает без uv на хосте.
`image_tag: X.Y.Z` закрепляет образ релиза без префикса `v` (`KD_IMAGE_TAG` в `.env`);
без поля используется `latest`. `.env` и `docker-compose.yml` руками не править.

`disable_tools: [ed_*, live_*]` — необязательно: имена и маски инструментов, которых сервер не покажет агенту
(`KD2_DISABLE_TOOLS`). Предложить, только если человек говорит, что группа не нужна (нет обменов через
универсальный формат — `ed_*`, нет песочниц — `live_*`); по умолчанию не задавать. Проверка после шага 5 — в
`tools/list` клиента этих инструментов нет.

### Сервер на отдельной машине

Агенты работают на других машинах (сервер для команды, отдельный хост с серверами MCP) — спросить человека, это
его решение. Тогда в `projects.local.yaml` **машины сервера**:

- `bind` — интерфейс, на котором порт виден другим машинам: `0.0.0.0` или адрес машины;
- `token` — длинный общий секрет. Без него на внешнем интерфейсе `setup_local.py` откажется. Секрет вписывает
  человек — как пароль, в чате не спрашивать;
- `server_url` — адрес, по которому агенты достучатся до сервера: `http://<адрес машины сервера>:8060/mcp` (свой
  `port` — в нём же), не `localhost`.

`setup_local.py` берёт из `server_url` схему, хост и порт и передаёт их серверу как `KD2_PUBLIC_URL` — от этого
адреса сервер строит ссылки на файлы (`download_link`, `upload_link`). Без него сервер берёт адрес, по которому
агент пришёл к `/mcp`; за обратным прокси это может быть внутренний адрес — поэтому `server_url` должен быть
тем адресом, который видят агенты. Сервер видит только папки своей машины: проекты из `projects:` должны лежать на ней.
