# Шаблоны обработчиков: поиск, отказ, заполнение свойства, дозаполнение, параметр
Читать, когда пишете типовой обработчик правил обмена или ревьюите чужой.

Образцы — свои, не копии типовых макетов; где смотреть типовой аналог — сказано у образца (`rules_open` макета
→ `rules_get` или `handlers_export`). Ссылки `стр. N` — модуль объекта `КонвертацияОбъектовИнформационныхБаз`
(БСП 3.1.12). Перед кодом: фаза и база — таблица в `SKILL.md`; переменные события — `handlers_export` и
`handlers.md`; стандарты и исключения — `handlers.md`, «Стандарты кода для обработчиков». Имена реквизитов в
образцах условные — сверить со структурой своей стороны (`structure_object`).

## 1. `ПоследовательностьПолейПоиска` ПКО — варианты от узкого к широкому

Приёмник; вызов — `НайтиОбъектПоСсылке`, стр. 8911–8985, текст выполняется на стр. 8959. Переменные:
`НомерВариантаПоиска`, `СвойстваПоиска`, `ПараметрыОбъекта`, `СтрокаИменСвойствПоиска`, `ПрекратитьПоиск`,
`СсылкаНаОбъект`, `УстанавливатьУОбъектаВсеСвойстваПоиска` (стр. 15321–15323).

```bsl
// Ключ — ИНН; наименование — только когда ИНН пуст: его пишут в базах по-разному.
Если ЗначениеЗаполнено(СвойстваПоиска["ИНН"]) Тогда
	Если НомерВариантаПоиска = 1 Тогда
		СтрокаИменСвойствПоиска = "ИНН, КПП";
	ИначеЕсли НомерВариантаПоиска = 2 Тогда
		СтрокаИменСвойствПоиска = "ИНН, Наименование";
	Иначе
		ПрекратитьПоиск = Истина;
	КонецЕсли;
ИначеЕсли НомерВариантаПоиска = 1 Тогда
	СтрокаИменСвойствПоиска = "Наименование";
Иначе
	ПрекратитьПоиск = Истина;
КонецЕсли;
```

- Каждый вариант — новая строка полей; повтор прошлой строки, `ПрекратитьПоиск` или найденный объект — конец
  перебора (стр. 8970–8984). Вариантов не больше 10 (стр. 8940).
- В строке — только свойства поиска ПКО (ПКС с «Поиск»); прочие имена молча выпадают (`НайтиЭлементПоСвойствамПоиска`,
  стр. 8565–8574).
- Ключ проверять `ЗначениеЗаполнено`: пустой ключ уходит в условие запроса и находит чужой объект без ключа
  (`НайтиЭлементЗапросом`, стр. 8425–8463; pitfalls, «Пустой ИНН в поиске по ИНН»).
- `ПараметрыОбъекта` здесь заполнен, только если ПКС параметра с «Поиск»: до поиска читается лишь `<Ссылка>`
  (`ПрочитатьСвойстваПоискаИзФайла`, стр. 8228–8291), прочие параметры — после него (`ПрочитатьОбъект`,
  стр. 10705); иначе он `Неопределено` (pitfalls, «Параметр объекта в обработчике поиска не виден»).
- Исключение — ошибка 73 и прерывание загрузки (стр. 8967–8972). Типовой аналог — pitfalls, «Варианты поиска
  должны различаться».

## 2. `ПередВыгрузкой` ПКО — не выгружать по условию

Источник; вызов — `ВыгрузитьПоПравилу`, стр. 557–595, текст — стр. 577. Переменные: `Источник`, `Отказ`,
`ВходящиеДанные`, `ИсходящиеДанные`, `ИмяПКО`, `ПКО`, `НеЗамещатьОбъектПриЗагрузке`, `ВсеОбъектыВыгружены`,
`ТолькоПолучитьУзелСсылки`, `НеСоздаватьЕслиНеНайден` и др. (стр. 15092–15096).

```bsl
// Источник — объект выборки или ссылка, если правило вызвано для значения свойства другого объекта.
Если ОбщегоНазначения.ЭтоСсылка(ТипЗнч(Источник)) Тогда
	ПометкаУдаления = ОбщегоНазначения.ЗначениеРеквизитаОбъекта(Источник, "ПометкаУдаления");
Иначе
	ПометкаУдаления = Источник.ПометкаУдаления;
КонецЕсли;
Если ПометкаУдаления = Истина Тогда // по пустой ссылке значение — Неопределено
	Отказ = Истина; // только ставить: сбросом в Ложь можно отменить чужой отказ
КонецЕсли;
```

- `Отказ` здесь снимает и объект, и ссылку на него: ссылочные свойства других объектов придут пустыми
  (стр. 590–593). Не выгружать объект сам, но оставить ссылку — `ПередВыгрузкойОбъекта` ПВД (`ВыгрузкаОбъектаВыборки`,
  стр. 13626–13628; `pvd.md`).
- `Источник` — объект или ссылка (`handlers.md`, «Ключевые переменные по фазам»; стр. 13208).

## 3. `ПередВыгрузкой` / `ПриВыгрузке` ПКС — заполнить свойство приёмника

Источник; `ВыгрузитьСвойства`: `ПередВыгрузкой` — стр. 12917–12964 (текст — стр. 12941), `ПриВыгрузке` —
стр. 13046–13093 (текст — стр. 13071). Переменные: `Источник`, `Приемник`, `ОбъектКоллекции`, `Значение`,
`Пусто`, `Выражение`, `ТипПриемника`, `ИмяПКО`, `ВыгрузитьОбъект`, `Отказ` и др. (стр. 15350–15353,
15399–15402).

```bsl
// ПередВыгрузкой ПКС без источника: значение собирается из реквизитов источника.
Значение = СтрШаблон(НСтр("ru = 'Документ %1 от %2'"), Источник.Номер, Формат(Источник.Дата, "ДЛФ=D"));
```

```bsl
// ПриВыгрузке ПКС: прочитанное значение подогнать под реквизит приёмника.
Значение = Лев(СокрЛП(Значение), 100);
```

- `Значение`, заданное в `ПередВыгрузкой`, из источника не перечитывается; осталось `Неопределено` — значение
  читается по имени (`ПолучитьЗначениеСвойства`, стр. 12069–12072), а у ПКС без источника — по имени приёмника
  с молчаливой ошибкой (`pks.md`, «Выгрузка значения»). Пустое значение — `Пусто = Истина`.
- В строке табличной части данные строки — `ОбъектКоллекции`, а не `Источник` (`pks.md`, стр. 12091–12105).
- `ПриВыгрузке` ПКО со `СтандартнаяОбработка = Ложь` отключает выгрузку всех ПКС (стр. 989) — для одного
  свойства не нужен.

## 4. `ПослеЗагрузки` ПКО — дозаполнить перед записью

Приёмник; `ПрочитатьОбъект`, стр. 10987–11020 (текст — стр. 11005), до записи (стр. 11119, 11228). Переменные:
`Отказ`, `Ссылка`, `Объект`, `ПараметрыОбъекта`, `ОбъектМодифицирован`, `ИмяТипаОбъекта`, `ОбъектНайден`,
`Правило` (стр. 15294–15295).

```bsl
// Новому объекту — значение по умолчанию приёмника; найденный не перетираем.
Если Не ОбъектНайден И Не ЗначениеЗаполнено(Объект.Ответственный) Тогда
	Объект.Ответственный = Пользователи.ТекущийПользователь();
КонецЕсли;
```

- `Отказ = Истина` — объект не записывается (стр. 11046–11049); `ОбъектМодифицирован` не читается — объект
  пишется всегда (`handlers.md`).
- Реквизиты другого объекта — `ЗначенияРеквизитовОбъекта` только по заполненной ссылке: по пустой каждое поле
  `Неопределено` (`ОбщегоНазначения`, стр. 275–282, 306–307; pitfalls, «Обработчик падает в новом приёмнике»).
- Код берётся из правил корреспондента в приёмнике — правка в двух файлах (`ОбменДаннымиСервер`,
  стр. 10001–10083; `handlers.md`, «Где лежат правила загрузки»).

## 5. Параметр через `ИмяПараметраДляПередачи`

Отправитель: ПКС с `ИмяПараметраДляПередачи` уходит узлом `<ЗначениеПараметра>` (стр. 12691–12701), в поля
поиска не входит (стр. 6079–6082); приёмник у такого ПКС может быть пустым (`ЗагрузитьПКС`, стр. 5494).
Получатель: `ПараметрыОбъекта[Имя]` — в `ПослеЗагрузки` (стр. 10702–10705, 10994), в обработчике поиска — только
с флагом «Поиск» (стр. 8228–8291).

```bsl
// ПослеЗагрузки: параметра может не быть (старые правила отправителя).
ВидЛица = Неопределено;
Если ПараметрыОбъекта <> Неопределено Тогда
	ВидЛица = ПараметрыОбъекта["ВидЛица"];
КонецЕсли;
Если ЗначениеЗаполнено(ВидЛица) Тогда
	// …заполнить реквизиты приёмника по виду лица
КонецЕсли;
```

- `ПараметрыОбъекта` — Соответствие или `Неопределено`, если параметров нет (стр. 9783–9789).
- Строки табличной части — `ПараметрыОбъекта["<ИмяТЧ>ТабличнаяЧасть"]`, таблица с `НомерСтроки` (стр. 9111–9113,
  9314, 9322; `pks.md`, «Параметры»).

## Чек-лист ревью кода обработчика

- [ ] Фаза и база верны: выгрузочный — API источника, загрузочный — API приёмника (`handlers.md`, таблица
      «Где и когда вызывается»).
- [ ] Переменные — из `handlers_export`; недокументированные локальные переменные исполнителя видны, но
      меняются между версиями БСП (стр. 13526; `handlers.md`, «Как выполняется код»).
- [ ] В выгрузочном нет записи в базу и блокировок: при ошибке выгрузка откатывается целиком (стр. 18515–18521),
      а выгрузка не должна менять источник (вывод).
- [ ] Исключение = остановка всего обмена, при загрузке — откат сообщения (стр. 2503–2505, 2512–2514);
      «пропустить объект» — `Отказ`.
- [ ] Ссылка проверяется `ЗначениеЗаполнено` до чтения её реквизитов (`ОбщегоНазначения`, стр. 275–282);
      запросов в цикле нет (`handlers.md`, «Стандарты кода для обработчиков»).
- [ ] Загрузочная правка внесена и в правила корреспондента приёмника (`ОбменДаннымиСервер`, стр. 10001–10083).
- [ ] Синтакс-чекер чистый, `handlers_locate` для каждой ошибки (`mcp-1c.md`, «Проверка кода обработчиков»).
