# ПКС и группы ПКС: что пишется в правила и что с этим делает БСП
Читать, когда добавляете или правите свойства ПКО, табличные части, наборы записей и параметры.

Ссылки `(Процедура, стр. N)` — модуль `DataProcessors/КонвертацияОбъектовИнформационныхБаз/Ext/ObjectModule.bsl`
(БСП 3.1.12); `reference/kd2-cfg/…:N` — выгрузка КД 2.1.8.2. Грабли поиска — скилл `kd2-exchange-pitfalls`.
`УОД:N` — модуль объекта универсальной обработки `УниверсальныйОбменДаннымиXML` из той же выгрузки (версия
обработки 1.0.5.234, в другой версии строки сдвинуты); всё ниже — про обмен через план обмена.

## Поля ПКС в XML

Писатель — `reference/kd2-cfg/DataProcessors/ВыгрузкаКонвертации/Ext/ObjectModule.bsl:615-738` (дальше `:N` —
строки этого файла). Пустые теги не пишутся (`ДобавитьЭлемент`, :83-95), булевы — только если Истина.
Читатель — ЗагрузитьПКС (стр. 5470–5628) и ЗагрузитьПКГС (стр. 5280–5441).

- **атр. `Отключить`** (свойство :619, группа :693) — правило уходит в `СвойстваОтключенные`, не выгружается
  (ЗагрузитьПКС, стр. 5486–5488; ЗагрузитьПКГС, стр. 5282–5292).
- **атр. `Поиск`** (только свойство, :623) — свойство уходит в `<Ссылка>` (ЗагрузитьПКС, стр. 5494–5496).
  Внутри группы не действует: строка идёт в `ПравилаГруппы` (стр. 5331, 5498–5500).
- **атр. `Обязательное`** (:627) — действует как `Поиск` (стр. 5490–5492). КД ставит его сам, если имя приёмника
  подобно `%ЭтоГруппа%` (:1214-1216); при загрузке `ЭтоГруппа` реквизиту не присваивается (стр. 8094, 10688):
  группа создаётся, только если в свойствах поиска `ЭтоГруппа = Истина` (СоздатьНовыйОбъект, стр. 7873–7881), без
  `ЭтоГруппа` среди свойств поиска новые объекты — элементы. То же умолчание ставит сервер при создании ПКС; явное
  значение в `fields` сильнее, заметка — в `warnings`. Универсальная обработка `Обязательное` не читает: ПКС без
  «Поиск» там обычное свойство (УОД:3624–3643), `ЭтоГруппа` только с `Обязательное` группы не создаёт (вывод:
  УОД:6465–6475, 8740–8746).
- **`НеЗамещать`** — атрибут `НеЗамещать` у `<Свойство>` (стр. 12972–12976) или у `<ТабличнаяЧасть>` /
  `<НаборЗаписей>` (стр. 11615–11619, 11642–11646): у найденного объекта значение не меняется.
- **`Код`** — `Имя` правила, из него строятся имена обработчиков (стр. 5534–5535, 5581–5588).
- **`Наименование`, `Порядок`** — `Порядок` задаёт порядок выгрузки: верхний уровень сортируется
  (ЗагрузитьСвойства, стр. 5668–5670). `Описание`, `Комментарий` читатель не разбирает.
- **`ПолучитьИзВходящихДанных`** — значение берётся из `ВходящиеДанные` (см. «Выгрузка значения»).
- **`<Источник Имя Вид [Тип]>`, `<Приемник Имя Вид [Тип]>`** — `Тип` пишется только при единственном типе
  свойства (:649-653, :663-667, :1202-1212); у группы `Тип` нет. Без источника — `Имя=""` (:104-112).
  `Вид` обычного свойства исполнитель не смотрит, кроме `ВидыСубконтоСчета` (стр. 12873–12878); у группы `Вид`
  определяет коллекцию и узел.
- **`КодПравилаКонвертации`** — ПКО значения (см. ниже). У группы читается (стр. 5353), но
  `ВыгрузитьГруппуСвойств` его не использует.
- **`ПриводитьКДлине`** — см. «Приведение длины». **`ИмяПараметраДляПередачи`** — см. «Параметры».
- **`ПоискПоДатеНаРавенство`** — атрибут у `<Свойство>` (стр. 12843–12846, 12978–12982): документ ищется
  запросом, а не `НайтиПоНомеру(Номер, Дата)` (НайтиСсылкуНаДокумент, стр. 8524–8550).
- **Группа: `ВыгружатьГруппуЧерезФайл`** (:712) — коллекция пишется через временный файл; так же при > 1000
  строк (ВыгрузитьГруппуСвойств, стр. 11780–11782).
- **Обработчики** `ПередВыгрузкой`, `ПриВыгрузке`, `ПослеВыгрузки` — у свойства на значение, у группы на каждую
  строку коллекции (стр. 11822–11976); `ПередОбработкойВыгрузки`, `ПослеОбработкиВыгрузки` — у группы на всю
  коллекцию (стр. 11542, 12002).

Тегов «выгрузить объект по ссылке», `НеОчищатьНаборЗаписей`, `ПоискПоТабличнымЧастям` у ПКС нет:
- «Выгрузить объект целиком» — переменная `ВыгрузитьОбъект` в `ПередВыгрузкой`/`ПриВыгрузке` ПКС, исходно `Ложь`
  (ВыгрузитьСвойства, стр. 12924, 12949, 13053, 13078; объект выгружает свойства с `ВыгрузитьТолькоСсылку =
  Истина`, ВыгрузитьПоПравилу, стр. 1019). Когда объект уходит целиком без флага — pitfalls, «Объект по ссылке».
- `НеОчищать` — переменная `ПередОбработкойВыгрузки` группы (ВыгрузитьГруппуСвойств, стр. 11537, 11621–11625,
  11648–11652). Без неё набор записей в приёмнике очищается (ЗагрузитьДвижения, стр. 9398–9405).
- `ПоискПоТабличнымЧастям` — тег ПКО; его строит БСП отправителя (см. «Табличная часть»).

## Выгрузка значения (ВыгрузитьСвойства, стр. 12775–13309)

1. **Упрощённая выгрузка** — нет обработчиков, `ПолучитьИзВходящихДанных`, `КодПравилаКонвертации`, `Тип`
   источника = `Тип` приёмника ∈ {Строка, Число, Булево, Дата} (ЗагрузитьПКС, стр. 5618–5624): значение пишется
   как есть, пустое — узлом без `<Значение>` (стр. 12824–12871).
2. `ПередВыгрузкой` может задать `Значение`, `Пусто`, `Выражение`, `ТипПриемника`, `ИмяПКО`, `НеЗамещать`,
   `Отказ` (стр. 12918–12964). Заданное `Значение` из источника не перечитывается (ПолучитьЗначениеСвойства,
   стр. 12071). `Выражение` уходит узлом `<Выражение>` и вычисляется в приёмнике (ПрочитатьСвойство,
   стр. 8054–8057).
3. **Откуда значение** (ПолучитьЗначениеСвойства, стр. 12069–12160):
   - `ПолучитьИзВходящихДанных` — `ВходящиеДанные[Приемник]`, при пустом приёмнике —
     `ВходящиеДанные[ИмяПараметраДляПередачи]` (стр. 12075–12087);
   - строка коллекции группы — `ОбъектКоллекции[Источник]`, при пустом источнике — `[Приемник]` (стр. 12091–12105);
   - иначе `Источник[Источник]`; **пустой источник → `Источник[Приемник]`, ошибка чтения молча глотается**
     (код 14 в протокол не пишется, стр. 12131–12134, 12154). ПКС без источника выгрузит реквизит источника
     с именем приёмника, если такой есть, иначе — узел без значения.
4. **Тип в сообщении** — `Тип` приёмника из правил; пуст и есть `КодПравилаКонвертации` — тип приёмника ПКО
   (стр. 12995–13005); для пустого значения — по значению (ОпределитьТипДанныхДляПриемника, стр. 12631–12654).
5. **Пустое значение** (`Пусто` или не `ЗначениеЗаполнено`) — узел без значения (стр. 13103–13126): ПКО и ПКЗ не
   вызываются, для пустого перечисления ПКЗ не нужно.

### Ссылочное значение и `КодПравилаКонвертации`

- С кодом — `ВыгрузитьПоПравилу` этого ПКО (стр. 13208); в свойство — `<Ссылка>`, `<Значение>` (ПКЗ) или `<Нпп>`
  (стр. 13224–13253). Кода нет в правилах — протокол 45 «Не найдено правило конвертации объектов», свойство
  пропущено (ВыгрузитьПоПравилу, стр. 341–349; ВыгрузитьСвойства, стр. 13211–13213).
- Без кода — ПКО по типу значения `Менеджеры[Тип].ПКО` (стр. 13152–13164): последнее загруженное ПКО с этим
  `Источник` (ЗагрузитьПравилоКонвертации, стр. 5845; ВосстановитьПравилаИзВнутреннегоФормата, стр. 7083–7085).
  Справка КД: из нескольких — с большим `Порядок`
  (`reference/kd2-cfg/Catalogs/ПравилаКонвертацииСвойств/Ext/Help/ru.html`).
  **ПКО для типа нет — свойство молча не выгружается**, протокол пуст (стр. 13154–13162).
- У ПКО значения есть `ПоследовательностьПолейПоиска` — атрибут `ИмяПКО` у свойства (стр. 13008–13014), приёмник
  ищет значение по этому ПКО (ПрочитатьОбъект, стр. 10678, 10700).

### Приведение типов

На выгрузке, только без ПКО (ОпределитьВозможностьУстановкиЗначения, стр. 12495–12629):
- Строка → Число/Булево/Дата/ХранилищеЗначения/УникальныйИдентификатор — `Число()`, `Булево()`, `Дата()`…
  (стр. 12499–12521). Вызов вне `Попытка`: нечисловая строка в `Число` — исключение (где ловится — не проверено).
- Строка → тип не из списка (например `ПеречислениеСсылка.X`) — уходит как есть; в приёмнике это имя значения
  перечисления (одНайтиОбъектПоСвойству, стр. 3907–3909).
- Число → Строка/Булево; Дата → Строка (`Лев(Строка(), 10)`); Булево → Число; УИ → Строка (стр. 12529–12613).
  Прочие сочетания (например Число → ссылка) — ищется ПКО по типу значения, нет — свойство пропущено.
- Пустой `Тип` приёмника у примитива — тип берётся из значения и пишется атрибутом (например стр. 12522–12525).

На загрузке: `Тип` из атрибута, иначе из блока `ИнформацияОТипахДанных`, который отправитель строит из `Тип`
приёмников ПКС (ТипСвойстваПоДополнительнымДанным, стр. 8213–8226; ЗаполнитьИнформациюПоТипамДанныхПриемника,
стр. 15968–15994). Примитивы — `XMLЗначение` (одЗначениеЭлемента, стр. 4512–4521); ссылка строкой: перечисление
по имени, прочее — предопределённый по имени, затем по коду, иначе пустая ссылка (одПолучитьЗначениеПоСтроке,
стр. 3981–4009; одНайтиОбъектПоСвойству, стр. 3920–3928). Узел без значения при известном типе — пустое значение
типа (ПрочитатьСвойство, стр. 8044–8048).

Свойство, которого у объекта приёмника нет (`Объект[Имя] = NULL`), а также `ЭтоГруппа` и `НеЗамещать` у
найденного объекта — молча пропускаются (ПрочитатьОбъект, стр. 10686–10693).

### Приведение длины

`ПриводитьКДлине` — **не обрезка, а форматирование кода/номера**: префикс + нули + числовая часть до длины
(ВыполнитьПриведениеЗначенияКДлине, стр. 12656–12660; ПривестиНомерКДлине, стр. 3694–3722). КД ставит флаг сам
только для строковых `Код`/`Номер` разной длины (`reference/kd2-cfg/Catalogs/ПравилаКонвертацииСвойств/Ext/
ObjectModule.bsl:40-62`). Текстовый реквизит без цифр добьётся нулями — на такие свойства флаг не ставить.

## Группа ПКС: табличная часть и набор записей

- **Узел по `Вид` приёмника** (ВыгрузитьГруппуСвойств, стр. 11609–11652): `ТабличнаяЧасть` → `<ТабличнаяЧасть>`;
  `НаборДвижений*`, `НаборЗаписейПоследовательности` → `<НаборЗаписей>`; иной `Вид`, в т.ч. пустой, — «простая
  группировка», свойства выгружаются на уровень объекта (стр. 11654–11710). `ПодчиненныйСправочник` — ни узла,
  ни коллекции (стр. 11627–11629, 11762–11763).
- **Коллекция** (стр. 11715–11778): из `ПередОбработкойВыгрузки` (`КоллекцияОбъектов`); `ПолучитьИзВходящихДанных`
  — `ВходящиеДанные[Приемник]`; `Вид` источника `ТабличнаяЧасть` — `Источник[Источник]`; `НаборДвижений*` —
  движения документа; пустой источник — `Источник[Приемник]`. `РезультатЗапроса` выгружается в таблицу.
- Строка коллекции — `<Запись>` со свойствами из `ПравилаГруппы` (стр. 11870–11875, 11921–11926).
- Группа в группе не поддерживается: `ЗагрузитьПКГС` разбирает только `<Свойство>`, конец вложенной `<Группа>`
  закрывает внешнюю (стр. 5322, 5374–5375).

**Загрузка табличной части** (ЗагрузитьТабличнуюЧасть, стр. 9162–9279). Ключ строки — все включённые приёмники
ПКС группы: отправитель пишет их в тег ПКО `ПоискПоТабличнымЧастям` (ЗагрузитьПКС, стр. 5525–5530;
ЗагрузитьПравилоКонвертации, стр. 6039–6070), приёмник читает (стр. 5999–6017; КлючевыеПоляПоискаПоТабличнойЧасти,
стр. 9349–9370); нет тега — все реквизиты ТЧ (стр. 9169–9183). Строки группируются по ключу: где число строк с
ключом в объекте и в сообщении совпало, **остаются строки объекта со всеми их реквизитами**, иначе — строки
сообщения; строк, которых нет в сообщении, не остаётся (стр. 9202–9258). Непереданные колонки ТЧ так
сохраняются только у совпавших строк.

**Набор записей** очищается и заполняется заново, если обработчик не выставил `НеОчищать` (ЗагрузитьДвижения,
стр. 9393–9405); поиска по строкам набора нет (`ДанныеПоискаПоТЧ = Неопределено`, стр. 9389). `НеЗамещать`
группы у найденного объекта — вся ТЧ или набор пропускается (ПрочитатьОбъект, стр. 10896–10904).

## Параметры (`ИмяПараметраДляПередачи`)

- Выгрузка: узел `<ЗначениеПараметра Имя="…">` (СоздатьСложнуюИнформациюДляЗаписиВXML, стр. 12691–12701);
  в `ПоляТаблицы`/`ПоляПоиска` ПКО не входит (ЗагрузитьПравилоКонвертации, стр. 6079–6082).
- Загрузка, объект: `ПараметрыОбъекта[Имя]`, `Соответствие` (ПрочитатьОбъект, стр. 10702–10705;
  ДобавитьПараметрПриНеобходимости, стр. 9783–9790). Передаётся в `ПослеЗагрузки` (стр. 10994). В обработчике
  поиска и `ПриЗагрузке` — только параметры с флагом «Поиск», прочитанные из `<Ссылка>` (pitfalls, «Параметр
  объекта в обработчике поиска не виден»).
- Загрузка, строки ТЧ: `ПараметрыОбъекта["<ИмяТЧ>ТабличнаяЧасть"]` — `ТаблицаЗначений` с колонкой `НомерСтроки`
  (с 0) и колонкой на параметр (стр. 9111–9113, 9314, 9322; ДобавитьСложныйПараметрПриНеобходимости,
  стр. 9793–9822). Набор записей — ключ `"<ИмяРегистра>НаборЗаписей"` (стр. 9382, 9486–9487).

## Служебные свойства

- `{УникальныйИдентификатор}` — не ПКС из КД: при `СинхронизироватьПоИдентификатору` БСП сама добавляет такое
  свойство поиска (ЗагрузитьПравилоКонвертации, стр. 5868–5876) и пишет GUID ссылки источника с `Тип="Строка"`
  (ВыгрузитьСвойства, стр. 12880–12894). Ветка выбирается по `Имя` (= `Код` ПКС, стр. 5535).
- `{ИмяПредопределенногоЭлемента}` — пишется в `<Ссылка>` при ПКЗ на предопределённый элемент (см. `pkz.md`).
- Оба при загрузке реквизитам не присваиваются (УстановитьРеквизитыПоискаУОбъекта, стр. 8094–8102).
