# Загрузка правил в базу
Читать, когда комплект правил не загружается в базу или загрузка предупреждает, что правила для другой программы.

## Комплект не загружается: «правила предназначены для другой программы»

- **Симптом:** форма загрузки правил синхронизации отклоняет ZIP — «Правила не могут быть загружены, так как они
  предназначены для программы …», только «Закрыть»; или предупреждение «Синхронизация данных может работать
  некорректно…» с «Продолжить» / «Отмена».
- **Причина:** загрузка комплекта из трёх файлов сверяет заголовок `ExchangeRules.xml`, элемент `<Источник>`:
  текст (имя конфигурации) без учёта регистра с `Метаданные.Имя` без «БАЗОВАЯ» — не совпало, отказ; атрибут
  `ВерсияКонфигурации` по первым трём числам — не совпало, предупреждение (РПО, стр. 43–95, 729–735, 961–967).
  Типично: в комплект положен чужой `ExchangeRules.xml` (правила корреспондента) или правила другой конфигурации.
- **Проверка:** `<Источник>` в `ExchangeRules.xml` комплекта — имя конфигурации базы, куда грузят
  (`rules_overview` — стороны правил).
- **Исправление:** `ExchangeRules.xml` — правила этой базы. Проверку выключает настройка плана обмена
  `ПредупреждатьОНесоответствииВерсийПравилОбмена = Ложь` (РПО, стр. 39–41) — это конфигурация, не правила.
  Что ещё сверяется и что нет — `kd2-rules-build/references/live-rules.md`, «Проверка заголовка при загрузке».
