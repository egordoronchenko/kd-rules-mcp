# Грабли обменов КД 2 через БСП

Справочник проверенных случаев, не привязанных к конкретной конфигурации. Каждый подтверждён кодом исполнителя
правил БСП (обработка `КонвертацияОбъектовИнформационныхБаз`) — именем процедуры и строками БСП **3.1.12**; в другой
версии строки сдвигаются, процедуры те же. Что значат обозначения ссылок (`РПО`, `УОД`, общие модули) —
`references/method.md`.

## Как разбирать жалобу

Диагноз человеку — со ссылкой на процедуру и строки БСП, а не только на строку файла правил. Шаги целиком, с
доказательствами — `references/method.md`.

0. Есть текст ошибки — `references/protocol.md`; жалоба словами — `references/symptoms.md`.
1. **Направление и база.** Загрузку в Б исполняет копия правил в Б — правила корреспондента комплекта Б; ошибка
   загрузки правится в `ExchangeRules.xml` комплекта А **и** в правилах корреспондента Б.
2. **Живые правила из обеих баз** (ZIP из базы): `rules_open` → `rules_validate` с обеими структурами.
3. **ПКО проблемного объекта** — `rules_get`: флаги, ПКС с `search: true`, `ПоследовательностьПолейПоиска`; как
   объект уходит — ПВД и ПКС других ПКО.
4. **Сравнить с типовым макетом** плана обмена — что доработано; макет действует, только если правила в базе взяты
   из него.
5. **Данные** — сервер данных песочницы, только чтение и только с согласия человека; нет согласия — «не
   проверено». Серверы 1С — по `kd2-rules-build/references/mcp-1c.md`.
6. **Правка** — по скиллу `kd2-rules-build`: правила конвертации — только сервером, не руками; правила
   регистрации — `registration_build`, обработчики — правкой файла побайтово; затем `rules_validate` и `bsp_check`.

## Куда читать

Один справочник на жалобу. Порядок разбора — раздел выше.

| О чём жалоба | Справочник |
|---|---|
| Текст ошибки, код протокола, обмен завершился «Ошибка» | `references/protocol.md` |
| Жалоба словами, без текста ошибки | `references/symptoms.md` |
| Задвоился, связался с чужим, не находится, пустой ключ поиска | `references/search.md` |
| После сбоя часть объектов уже в приёмнике, обработчик падает, документ не проведён | `references/loading.md` |
| Проверить исправление живым обменом | `references/exchange-check.md` |
| Объект не выгружается, уходит только ссылкой, реквизит пуст без ошибки | `references/export.md` |
| Перечисление: «Не найдено соответствие для значения Источника», код 71 | `references/enums.md` |
| Объект в приёмнике удалился, а не пометился | `references/deletion.md` |
| Комплект не загружается, «правила для другой программы» | `references/rules-load.md` |
| Правило регистрации не работает, узел ничего не получает, пришло удаление живого | `references/registration.md` |
| Ручная выгрузка универсальной обработкой ведёт себя иначе, чем план обмена | `references/manual.md` |
| Обозначения ссылок на БСП, шаги разбора с доказательствами, как пополнять скилл | `references/method.md` |

## Как пополнять

Только универсальное и только с доказательством (процедура и строки БСП или воспроизведение в песочнице); формат —
симптом → причина → проверка → исправление; находка — в справочник своей темы. Правила целиком —
`references/method.md`, «Как пополнять».
